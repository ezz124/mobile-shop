# Mbile ERP — نظام إدارة متاجر الهواتف النقّالة

نظام إدارة متكامل لمتاجر الهواتف النقّالة — تطبيق ويب عربي RTL متصل بقاعدة PostgreSQL على Supabase، بواجهة كاملة بخط **Rubik** وهوية زرقاء/خضراء مستوحاة من فلسفة Apple التصميمية.

A complete, production-ready Mobile Phone Store Management System: Arabic-first, web-first, Supabase-backed.

## التشغيل

```bash
npm install        # تثبيت الحزم + توليد Prisma Client
npm run dev        # تشغيل الواجهة وخادم الـ API للتطوير
```

- قاعدة البيانات تُنشأ على PostgreSQL بعد تنفيذ `npm run db:push`.
- **الحساب الافتراضي:** `admin` / `admin123` (غيّر كلمة المرور من الإعدادات).

### بناء وتشغيل إنتاجي

```bash
npm run build      # بناء الواجهة وخادم الـ API
npm run web:start  # تشغيل نسخة الويب المبنية
```

## التقنيات

React 18 + TypeScript (strict) • Express • PostgreSQL + Prisma ORM • Tailwind CSS • React Router • React Hook Form + Zod • TanStack Query • Framer Motion • Lucide React • Recharts • bcryptjs (جلسات آمنة)

## الوحدات

لوحة التحكم • نقطة البيع POS (باركود + IMEI) • المنتجات • الهواتف (تتبع IMEI فردي) • الملحقات • المخزون (حركات وجرد وتنبيهات) • المبيعات • المشتريات • العملاء (ديون) • الموردون (ذمم) • المصروفات • الصندوق (دفتر مالي كامل) • المرتجعات (بيع/شراء، كلي/جزئي) • الفواتير (طباعة حرارية 80mm أو A4) • التقارير • المستخدمون والصلاحيات (5 أدوار) • الإعدادات • النسخ الاحتياطي والاستعادة (يدوي + تلقائي + فحص سلامة).

## سلامة البيانات

- كل عملية (بيع/شراء/مرتجع/دفعة/مصروف) تُنفَّذ داخل **معاملة قاعدة بيانات (Transaction)** واحدة: تحديث المخزون + أجهزة IMEI + الدفعات + حركات الصندوق + الديون + سجل التدقيق.
- الأرصدة والديون **محسوبة من السجلات** (وليست حقولاً قابلة للانحراف)، ما يمنع تلف الأرصدة.
- حذف الفواتير يعكس كل آثارها تلقائياً (مع منع الحذف عند وجود مرتجعات أو أجهزة مبيعة).
- النسخ الاحتياطي بصيغة JSON على الخادم، مع الاعتماد على نسخ Supabase لاستعادة قاعدة البيانات بالكامل.

## التطوير في المتصفح

`npm run dev` يشغّل الواجهة وخادم الـ API الحقيقيين، وتستخدم الواجهة Proxy تلقائيًا للاتصال بالخادم.

## تشغيل نسخة الويب مع PostgreSQL

نسخة الويب تستخدم نفس واجهة React الحالية، مع خادم API مستقل في `server/` وقاعدة PostgreSQL بدلاً من SQLite.

1. أنشئ مشروعًا على Supabase وخذ رابط الاتصال الـ Pooler وضعه في `DATABASE_URL`، والرابط المباشر في `DIRECT_URL`.
2. نفّذ `npm run db:push` لإنشاء الجداول، ثم `npm run web:start`.

3. افتح `http://localhost:3001`.

Docker اختياري فقط لتشغيل PostgreSQL محليًا أثناء التطوير، وليس مطلوبًا عند استخدام Supabase.

الحساب الافتراضي بعد تهيئة قاعدة البيانات: `admin` / `admin123`.
